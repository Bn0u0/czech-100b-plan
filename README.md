# 捷克百億計劃

青年百億海外圓夢基金計畫｜海外翱翔組 **M-4-12 捷克文學與民主韌性** 申請及數位文化策展專案。

## 官方計畫
- 提案單位：東吳大學；類別：文化及藝術交流。
- 日期：2027-04-01 至 2027-04-18，**含飛行日 18 天**。
- 地點：捷克布拉格、奧地利維也納；名額：20 人。
- 見習機構：捷克文學館（Museum of Czech Literature）、摩拉維亞圖書館（Moravian Library）。
- 18–30 歲中華民國國籍青年可申請；具中東歐相關課程／知識證明、初級捷克語能力為優先條件。
- 行前培訓：2027 年 2 月及 3 月各一天，共 16 小時，未參加視同放棄。
- 經費規劃總額：NT$230,670，包含合作單位辦理項目及青年自理項目，**不是全部直接撥給個人的現金**。

以上依據使用者提供之《M-4-12 小簡章》（9 頁）；具體行程得調整。

## 專案目標
1. 準備符合官方要求的申請資料；避免誤將展示性作品當成官方必繳作品集。
2. 製作繁體中文的捷克文學、歷史與民主韌性互動網站。
3. 以網站支持返台策展與文化傳播；網站不取代官方要求的其他成果。
4. 以史料來源與素材授權優先，區分已完成／計畫中功能。
