# 捷克文學與民主韌性互動網站｜MVP

## 定位
面向台灣讀者的繁體中文數位文化策展。核心為捷克文學、歷史與民主韌性，不是一般觀光攻略。

## MVP 三個頁面
1. **文學與城市**：布拉格作家地圖、卡夫卡／赫拉巴爾等地景與有據可查的介紹。
2. **歷史與民主**：事件時間軸，呈現民主轉型、地下文學、布拉格之春與天鵝絨革命。
3. **展覽與成果**：精選文獻解說、台捷文化比較與未來實地學習成果欄位。

## 技術建議
- Next.js + TypeScript：網站主體。
- MapLibre GL JS：地圖與捲動章節鏡頭。
- 互動時間軸：先採簡單的可存取 React 元件，再評估 timel.in 及其維護狀態。
- 捲動敘事：參考 ScrollCraft、Telar 的互動方式，不直接複製含有不明授權的素材。
- 內容：Markdown/MDX + 清楚引用、時間、圖片署名及授權資訊。

## 實作順序
1. 完成設計系統、內容資料格式與手機版。
2. 建立 3 個有來源的歷史／文學故事。
3. 加入地圖、時間軸與基本捲動動效。
4. 進行可用性、效能、史實與授權檢查。
5. 公開 Demo，申請書引用網址及截圖。

## 驗收
- 內容可在手機端閱讀；低動態偏好可停用大幅動畫。
- 每項史實有來源；歷史解釋與個人觀察清楚區分。
- 無未授權圖像／長篇引用。
- 不把未完成功能稱作已完成成果。
